High Incident — Lateral movement across a shared carrier network

An attacker crossed a shared private cellular network from one operator’s site into another’s plant

CERT Polska’s follow-up report describes an intrusion that began at a wind farm and ended at an unrelated combined heat and power plant, where a turbine was taken out of service. The bridge was a private APN both organisations bought from the same carrier. A private APN is an addressing and billing construct, not a security boundary. Railroads and transit agencies should read this closely because cellular is the default connectivity for anything trackside: crossing monitors, signal-house telemetry, defect detectors, remote switch heaters, station equipment and positive train control backhaul. If those devices sit on a shared APN and can address one another, the isolation you assumed may not exist.

Until you have that answer, treat every cellular-attached wayside device as internet-exposed: place a firewall you control between the modem and anything operational, disable inbound management on the modem, and use per-site credentials rather than one password across the territory. Then confirm wayside sites cannot reach each other laterally, which is the specific failure documented here.

High Research — AI-assisted exploit porting against PLCs

Researchers used an AI model to port a working PLC exploit to a sibling controller — then bricked one

Forescout’s Vedere Labs set a large language model the task of taking a working remote-code-execution exploit for one WAGO controller — the 750-852, via CVE-2021-31886, a pre-authentication buffer overflow in its Nucleus FTP server — and re-targeting it at a related model, the 750-831. It worked, but not cheaply or unattended: the final stage alone ran more than eight hours and over $500 in API costs, with a researcher steering throughout. A later session aimed at building a command-and-control implant wrote a payload into flash-mapped memory and permanently bricked the test controller. For rail and transit the relevant detail is fleet uniformity in reverse: wayside, station and depot control estates are assembled from close variants of the same controller families, and an exploit proven on one variant is now materially cheaper to move onto its siblings.

Critical Critical Advisory — Actively exploited, KEV-listed

A CVSS 10 pre-auth flaw in SonicWall’s SMA1000 remote-access gateway is being exploited, and CISA gave agencies three days

SonicWall disclosed on 1 September that two previously unknown vulnerabilities in its SMA1000 secure remote access gateway and SSL-VPN appliance are being exploited in the wild; the company says it found both the flaws and the exploitation internally. CVE-2026-83548, scored CVSS 10, is a pre-authentication server-side request forgery in the Appliance Work Place interface. CVE-2026-83549, at 7.8, is an operating-system command injection flaw in the Appliance Management Console. Chained, the pair gives an unauthenticated attacker remote code execution on the appliance itself. CISA added both to the Known Exploited Vulnerabilities catalog on 2 September with a 5 September deadline for federal civilian agencies, and marked both entries as requiring forensic triage under Binding Operational Directive 26-04 — a signal that patching alone does not close the incident. Affected models are the SMA1000 6210, 7210 and 8200v; SSL-VPN running on SonicWall firewalls and the SMA 100 series are not affected.

Critical Advisory — Actively exploited, CISA KEV, historian and MES databases

A seven-year-old SQL Server flaw is now confirmed exploited — and it is the database under your historian

CISA added six vulnerabilities to the Known Exploited Vulnerabilities catalogue on 26 August, and the one that matters most on the plant floor is CVE-2019-1068, a remote code execution flaw in Microsoft SQL Server patched in July 2019 and only now confirmed as exploited in the wild. Successful exploitation runs code under the SQL Server Database Engine service account; where that account is over-privileged — which is common on systems installed by an integrator years ago — the attacker moves off the database and onto the Windows host. For a railroad or transit agency this is the database tier under asset management, the SCADA and signalling historian, the fare-collection back office and the maintenance records — commonly SQL Server instances that a systems integrator stood up during a capital project and that nobody has patched since the project closed out.
